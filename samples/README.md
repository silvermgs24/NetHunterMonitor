# Samples

`synthetic-beacon-sample.pcap` is **synthetic test data**, generated by `nethunter make-sample-pcap`. It is not real
traffic and contains no malware. It only uses documentation addresses (RFC 5737: 192.0.2.0/24, 198.51.100.0/24,
203.0.113.0/24) and the reserved `.example` top-level domain.

It contains:

| Pattern | What NetHunter should report |
|---|---|
| HTTPS to `203.0.113.50` every ~30 s (±10 %), TLS SNI `cdn-sync-update.example`, with a DNS lookup before each | **Possible C2 beacon**, interval ≈ 30 s |
| 40 TXT queries for long random subdomains of `exfil-data.example` (NXDOMAIN) | **Possible DNS tunnelling**, NXDOMAIN burst |
| 6 unanswered SYNs to `203.0.113.66:4444` | Failed connection attempts, Metasploit-default port |
| Irregular HTTPS to `news*.example` | Low risk (no detection) |

Open it in the app (**PCAP → Open capture…**) or run `nethunter pcap samples\synthetic-beacon-sample.pcap`.
Because packets carry no process information, every flow shows **Process: Unknown**, so the beacon is rated
SUSPICIOUS rather than HIGH (fewer independent signals are available than in live monitoring).

`example-iocs.txt` shows the accepted IOC list format. Copy it into `config\ioc\` (or use **IOC → Import IOC list…**)
to try local IOC matching against the sample capture.
